# Model manifest for the video_gen audio serverless worker (SFX / music).
#
# Format (tab-separated): <subdir>\t<filename>\t<URL>\t<sha256>\t<version>\t<license>
# Consumed by populate-volume.sh at worker boot (or by runpod.provision on the
# service side): files land in /runpod-volume/models/<subdir>/<filename>, which
# is exactly the layout extra_model_paths.yaml exposes to ComfyUI.
#
# Every URL is pinned to an immutable Hugging Face commit revision and every file
# has a pinned sha256 (the LFS oid). `main` is forbidden: populate-volume.sh
# rejects a URL without /resolve/<40-hex-commit>/ and fails with a readable error,
# so a non-pinned manifest never silently downloads moving weights.
#
# Version is the execution-fact value the worker reports as telemetry.engine_version;
# license is the value it reports as telemetry.license. Keep both in sync with the
# audio_models catalog snapshot on the service side.
#
# The worker executes a prepared ComfyUI API graph built by the service from
# audio_models.graph.template. The graph must reference exactly these file names:
#
#   Stable Audio 3.0 Small SFX (SFX, ~2.27 GB + text encoder ~1.19 GB):
#     checkpoints/stable_audio_3_small_sfx.safetensors
#     text_encoders/t5gemma_b_b_ul2.safetensors
#     license: Stability AI Community License (commercial outputs < $1M/year revenue,
#     > $1M requires Enterprise) — https://stability.ai/community-license-agreement
#
#   ACE-Step 1.5 turbo AIO (music, ~10.0 GB single checkpoint):
#     checkpoints/ace_step_1.5_turbo_aio.safetensors
#     license: MIT (ACE-Step/Ace-Step1.5 original weights; ComfyUI repack)
#     — https://github.com/ace-step/ACE-Step-1.5
#
# Volume budget: ~13.5 GB for the pinned set; attach at least 25 GB (ComfyUI
# outputs/temp + headroom for the MOSS reserve or Stable Audio 3 music later).
# Weights are never baked into the image or committed to git (see .gitignore).
#
# To add a model: add its files with pinned /resolve/<commit>/ URLs and sha256,
# run populate-volume.sh, then add the graph template to the `audio_models`
# catalog in video_gen. MOSS SoundEffect v2 is a catalog reserve and uses the same
# contract (no worker change) when its files are added here.
